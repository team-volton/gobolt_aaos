# 고볼트 (GoBolt)

평일 출퇴근부터 며칠짜리 여행까지, 일정 전체에 드는 전기를 미리 계산해서 언제, 어디서, 몇 %까지 충전하면 되는지 알려주는 Pleos Connect용 전기차 충전 플래너입니다.

현대자동차그룹 차량용 앱 개발 공모전 출품작 / Team Volt.On

## 주요 기능

- **일정 전체 전기 계산**: 이동, 현지 주행, 정차 중 공조로 나눠 필요한 전기를 계산하고 날짜별 잔량을 그래프로 표시
- **충전 계획안 비교**: 충전 횟수 최소, 소요 시간 최소, 잔량 여유 최대 3가지 계획을 나란히 비교
- **일상 모드**: 출퇴근 일정을 한 번 저장하면 7일간 귀가 잔량과 충전할 날 안내, 외근 추가 시 바로 재계산
- **여행 모드**: 내비 즐겨찾기에서 목적지 선택, 숙소/차박에 따른 다음 날 잔량과 복귀 충전 계획 재계산
- **충전소 대안**: 충전소를 빼고 다시 계획, 주행 중에도 다음 충전소를 바꿔 내비에 다시 전달
- **주행 중 요약과 운행 리포트**: 다음 충전소까지 거리와 도착 잔량 표시, 운행 후 계획 대비 실제 사용량 정리

## 실행 환경

- Pleos Connect 에뮬레이터 v2.1.0 (2560×1440)
- minSdk 28, targetSdk 35

## 시연 설정

- 설정 > 전비 기준을 **시연 4.0**으로 두면 아이오닉 9 기준값(배터리 110.3kWh, 전비 4.0km/kWh)으로 계산합니다. 기획서의 여행 시나리오와 같은 값이 나옵니다.
- **공인 + 기온**을 고르면 차량이 알려주는 배터리 용량과 전비를 우선 사용합니다.
- 여행 출발일이 오늘보다 이전이면 이미 진행 중인 일정으로 계산되니, 시연 전에 출발일을 다음 날 이후로 맞춰 주세요.

## 빌드

Android Studio에서 프로젝트를 열고 `app`을 실행하거나, 아래 명령을 사용합니다.

```bash
./gradlew :engine:test :app:assembleDebug
```

release 빌드는 프로젝트 루트의 `keystore.properties`가 있을 때만 서명됩니다. 서명 정보는 저장소에 포함하지 않습니다.

## 구조

| 모듈 | 역할 |
|---|---|
| `engine` | 안드로이드에 의존하지 않는 계산 엔진 (일정, 에너지, 충전 계획). 단위 테스트 31개 |
| `app` | Jetpack Compose 화면, 차량 데이터와 내비 연동, 알림 |

`app` 패키지

- `vehicle`: Vehicle SDK, 주행 제한 상태 수신
- `navi`: NaviHelper SDK 연동 (경로 계산, 주행 정보, 경유지 전달)
- `home`, `trip`, `settings`: 화면
- `data`: 일정과 설정 저장
- `notify`: 충전 안내 알림
- `ui`: 테마, 간격, 공통 컴포넌트

## 사용 SDK와 권한

| SDK / API | 용도 | 권한 |
|---|---|---|
| Vehicle SDK 2.3.2 | 배터리 잔량, 용량, 누적 주행 거리, 기어 상태, 전비, 공조 설정 온도 | `CAR_ENERGY`, `CAR_DRIVE`, `CAR_INFO`, `CAR_CLIMATE` |
| NaviHelper SDK 3.0.5 | 실제 거리와 추천 충전소, 주행 중 남은 거리와 도착 잔량, 즐겨찾기, 경유지 포함 경로 전달 | `NAVI_ROUTE`, `NAVI_ROUTE_SEARCH` |
| CarUxRestrictionsManager | 주행 중 입력 화면 잠금 | - |
| 시스템 알림 | 충전이 필요한 날 밤, 충전소 접근 시 안내 | `POST_NOTIFICATIONS` |

## 개발 메모

- 내비 경로 계산이 현재 위치에서 출발하는 구간만 되기 때문에, 복귀 거리는 가는 길 거리로 먼저 잡아 두고 목적지에 도착하면 내비로 다시 계산합니다.
- 내비에 넘길 수 있는 경유지가 2곳까지라 경유지와 충전소를 합쳐 앞의 2곳만 넘깁니다.
- 정차 중 공조 전력은 아직 실측값이 없어 초기값으로 계산하고 있고, 운행 기록이 쌓이면 보정할 계획입니다.
